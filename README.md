# West of Loathing – Save File Editor

A lightweight, user-friendly save file editor for **West of Loathing**, designed to let you modify your character stats, perks with ease.

## ✨ Features

- Read and edit existing save files
- Modify character XP, meat, skill, perk
- Simple UI and fast processing

## ⚠️ Compatibility Note

This editor is confirmed to work with the **GOG version** of **West of Loathing**.  
The **Steam version is currently untested**, but the save format is identical between both versions, so it will **most likely work** as well.  
If you encounter issues with the Steam version, please report them.

## 📁 Save File Location

### GOG Version (Windows)

`%USERPROFILE%\Appdata\LocalLow\Asymmetric Software\West of Loathing`

## 🛠️ How to Use

1. Locate your save directory (see above).
2. Make a **backup** of your save file (recommended).
3. Load the save file into the editor.
4. Edit the fields you want to change.
5. Save and overwrite your existing file.
